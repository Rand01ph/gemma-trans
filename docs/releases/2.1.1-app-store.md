# GemmaTrans 2.1.1 App Store 发布准备

## 发布范围

从 `v2.1.0`（`101735f`）发布独立补丁，修复长文翻译、卡片速率显示及翻译状态处理问题。正式 scheme 为 `GemmaTrans-MAS`，Bundle ID 为 `com.gemmatrans.GemmaTrans`；版本为 2.1.1，发布 build 为 40；已确认 App Store Connect 存在 build 27，因此不再使用原本的 build 26。

QA/Dev/UITest 构建只用于本地验证，不能用于 App Store 上传。正式构建不应包含 `GTChannel`，使用原始 AppIcon、生产设置域及沙盒 entitlement。

## 本次更新（简体中文）

- 修复长文章翻译可能只显示前半部分的问题，改善分段处理和翻译进度提示。
- 恢复翻译卡片右下角的生成速度显示。
- 改进停止、重试和连续翻译时的状态处理，提升稳定性。

## What's New (English)

- Fixed an issue where translations of long articles could stop before reaching the end. Improved text segmentation and progress feedback.
- Restored the generation speed indicator in the lower-right corner of the translation card.
- Improved state handling when stopping, retrying, or starting another translation.

## 审核测试说明草稿

本版本为本地翻译功能修复。首次运行需联网下载翻译模型，下载完成后可在本机翻译。可在主窗口输入长文章，或在支持 macOS 服务的文本应用中选中文字，选择“服务 → Translate with GemmaTrans”测试。等待所有段落翻译完成后，卡片右下角显示生成速度。可测试运行中的停止与重新翻译。

## 证据与发布门槛

- [翻译及 UI 验证](2.1.1-validation.md)：包含真实 MLX、低比特模型以及 32 场景基线证据。
- [通道隔离验证](../development/local-channels-validation.md)：最新 Swift 测试及真实 QA 服务入口结果；最新原生自动 UI 测试在开启自动化模式前超时，不能标记通过。
- 本轮 `script/ui_contract.py` 再次通过，能拒绝隐藏速率、移除复制按钮及布局重叠。
- 本机只有 Apple Development 签名身份，没有可直接导出 MAS 分发包的有效身份；本机为 macOS/Xcode 27，正式上传应使用 App Store 当前接受的稳定构建环境。
- `release-mas.yml` 当前不能直接用于发布；GitHub Secrets 缺少 `MAS_DIST_CERT_P12_BASE64`、`MAS_DIST_CERT_PASSWORD`、`MAS_INSTALLER_CERT_P12_BASE64`、`MAS_INSTALLER_CERT_PASSWORD`、`MAS_PROVISION_PROFILE_BASE64`。不能直接触发旧工作流期待成功上传。
- App Store Connect 登录后需核实：现有线上版本、待审核版本、最新 build、2.1.1 对应的 Xcode Cloud 仓库/分支/scheme、账号协议状态。发布源必须与已审阅的 2.1.1 修复提交一致。

## 最终交付顺序

1. 将 2.1.1 修复推送到独立分支并完成代码审阅。
2. 在固定图形环境补跑最新原生 UI 自动化，保留失败或通过的真实结果。
3. 在 App Store Connect 确认正确构建来源与 build 号，用稳定 Xcode 完成正式 MAS archive、export 和上传。
4. 等待 Apple 处理完成，确认 2.1.1 build 可选、签名/沙盒/模型下载正常，再关联版本并填写上述更新内容。
5. 提交审核及正式上架作为后续发布动作；本文件不表示已上传或已提交审核。
