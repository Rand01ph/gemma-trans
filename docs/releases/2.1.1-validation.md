# GemmaTrans 2.1.1 修复与验证报告

验证日期：2026-09-20。补丁基线：`v2.1.0` / `101735f`；分支：`codex/2.1.1-fixes`；版本：2.1.1 (26)。

## 交付行为

- 翻译卡片完成后在**右下角**显示 `xx.x tok/s`，与复制、朗读按钮同一行。顶部语言方向保留原位置。新任务、重试、无效数据及未完成任务不显示旧速率。
- 输入上限作用于每个分段；全文只识别一次方向，按原顺序串行处理，每段独立会话。状态行显示分段进度。
- 输出达到上限或上下文不足时拆分当前段重试，只追加成功完成的段落。失败、停止和关闭保留已提交段落并停止后续工作。
- 速率属于当前请求，使用成功提交段落的生成 token 总数 / 对应生成耗时；不计被丢弃的重试输出，不读取全局最后一次请求数据。
- 保留 `TranslationService.translate`、文本流、`fullText()` 和 HTTP 返回形式。增加进度、请求统计及明确未完成错误。未扩展 PopClip HTTP 客户端。
