# 快捷指令配置指引：快递短信自动变提醒事项

GemmaTrans 提供「本地 AI 处理」快捷指令动作：用本地 Gemma 模型按指令处理文本——
不联网、不要 API key、文本不离开设备。它的输出会作为变量回传快捷指令，
可以直接喂给「添加提醒事项」「存入备忘录」「发送通知」等系统动作。

本文以首发场景为例：**收到快递取件短信后，自动创建一条提醒事项**，形如
`取件: 丰巢 3 号柜 · 码 8821 · 今天 21 点前`。全程后台、零打开 app、零联网。
配置一次约 2 分钟。

## 前提

- iPhone 已安装 GemmaTrans，并在 app 内完成模型下载（约 3.6 GB，一次性）
- iOS 17 及以上（个人自动化的「当收到信息」触发器 + 「立即运行」开关）

## 配置步骤

1. 打开系统**快捷指令** app → 底部「**自动化**」标签 → 右上 **+** 新建个人自动化
2. 触发器选「**信息**」：
   - 「信息包含」填 **取件**
   - 发件人保持「任何人」
   - 勾选「**立即运行**」→ 完成
   - **「立即运行」必须开**：不开的话每次触发都会弹横幅等你手动确认，自动化形同虚设
3. 进入自动化的动作编辑，依次添加 3 个动作：
   1. 「**获取信息内容**」——拿到触发那条短信的正文
   2. GemmaTrans「**本地 AI 处理**」——
      「文本」选上一步的「信息内容」变量；「任务」选「**快递取件提取**」
   3. 「**添加提醒事项**」——标题选上一步「本地 AI 处理」的输出变量；
      列表建议建一个「取快递」专用列表
4. 保存。此后收到含「取件」的短信，几秒内提醒事项自动出现。

## 建议追加（可选）

- **过滤非快递短信**：在动作 2 和 3 之间加「如果」——
  如果「本地 AI 处理」的结果 **是「无」** → 「停止此快捷指令」。
  模型对验证码、营销等非快递短信会输出 `无`，这个分支避免误建提醒。
- **覆盖更多关键词**：触发器的「信息包含」只支持单个关键词；
  要同时覆盖「快递」「包裹」等，把整条自动化复制一份、只改关键词即可。
- **自定义任务**：在 GemmaTrans app 的「任务库」（主界面右上魔棒图标）里
  保存的自定义任务，会和内置预设一起出现在「任务」参数下拉里。

## 已知限制（如实告知）

- **短信无法自动标记已读**：iOS 不向第三方开放该能力，已读需手动处理。
- 自动化只能读到**触发那一条**短信的内容，不能扫描历史短信。
- 首次触发时后台冷加载模型约 3 秒——自动化是异步无人等待场景，基本无感。
