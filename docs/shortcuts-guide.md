# 快捷指令配置指引：快递短信自动变提醒事项

GemmaTrans 提供「本地 AI 处理」快捷指令动作：用本地 Gemma 模型按指令处理文本——
不联网、不要 API key、文本不离开设备。它的输出会作为变量回传快捷指令，
可以直接喂给「添加提醒事项」「存入备忘录」「发送通知」等系统动作。

本文以首发场景为例：**收到快递取件短信后，自动创建一条提醒事项**，形如
`取件: 丰巢 3 号柜 · 码 8821 · 今天 21 点前`。全程后台、零打开 app、零联网。
配置一次约 2 分钟。

## 前提

- iPhone 已安装 GemmaTrans，并在 app 内完成模型下载（约 3.6 GB，一次性）
- iOS 17 及以上（个人自动化的「当收到信息」触发器 + 「立即运行」开关）

## 配置步骤

1. 打开系统**快捷指令** app → 底部「**自动化**」标签 → 右上 **+** 新建个人自动化
2. 触发器选「**信息**」：
   - **「信息包含」必须填一个关键词**（如 **快递** 或 **取件**）——iOS 18/26 实测：
     触发器**必须有一个有效筛选条件才会触发**，发件人和内容**全留空不会触发任何短信**
     （顶部显示「符合以下条件」却没填有效条件 = 永不匹配）。这是配置成败的关键。
   - 发件人那行**别去碰**（留下空的「发件人 是 ___」反而会让触发器失效）；要限定发件人
     再点它选具体联系人
   - 勾选「**立即运行**」→ 完成
   - **「立即运行」必须开**：不开的话每次触发都会弹横幅等你手动确认，自动化形同虚设
3. 进入自动化的动作编辑，按下面的结构添加动作（**过滤分支不能省**，否则验证码等
   非快递短信也会建出空待办）：
   1. GemmaTrans「**本地 AI 处理**」——「文本」选「**快捷指令的信息**」（触发器传入的
      短信正文，无需单独的「获取信息内容」步骤）；「任务」选「**快递取件提取**」
   2. 「**如果**」——条件选「**本地 AI 处理的结果**」「**包含**」，值填「**无**」
   3. 在「如果」分支**内部**放「**停止此快捷指令**」（模型对非快递短信输出 `无`，
      命中即止，不建待办）；「否则」分支留空
   4. 「**结束如果**」
   5. 「**添加提醒事项**」——标题变量**务必选「本地 AI 处理的结果」**（不是「如果的
      结果」——那个是空的）；列表建议建一个「取快递」专用
4. 保存。此后任何快递取件短信，几秒内提醒事项自动出现，非快递短信被自动跳过。

> ⚠️ 易错点：① 标题用错变量（选成「如果的结果」）→ 待办标题空白；② 过滤条件写成
> 「是任何内容」→ 拦不住「无」，验证码也建待办。务必照上面的「包含 无 → 停止」配。

## 建议追加（可选）

- **过滤非快递短信**：在动作 2 和 3 之间加「如果」——
  如果「本地 AI 处理」的结果 **是「无」** → 「停止此快捷指令」。
  模型对验证码、营销等非快递短信会输出 `无`，这个分支避免误建提醒。
- **覆盖更多关键词**：「信息包含」只支持单个关键词，且触发器**必须有这个关键词才触发**
  （iOS 18/26 实测：无法配「任何短信都触发」，留空不工作）。要同时覆盖「快递」「取件」
  「包裹」等，把整条自动化复制一份、只改关键词即可。建议先用覆盖面最广的「快递」起步。
- **自定义任务**：在 GemmaTrans app 的「任务库」（主界面右上魔棒图标）里
  保存的自定义任务，会和内置预设一起出现在「任务」参数下拉里。

## 已知限制（如实告知）

- **短信无法自动标记已读**：iOS 不向第三方开放该能力，已读需手动处理。
- 自动化只能读到**触发那一条**短信的内容，不能扫描历史短信。
- 首次触发时后台冷加载模型约 3 秒——自动化是异步无人等待场景，基本无感。
- **「立即运行」会强制弹一条"已运行"通知**——Apple 对信息类触发器的硬性要求，无法静默。
- 锁屏时触发正常，但个别后续动作可能受限（社区报告不一）；链路延迟约 15 秒量级。
- iOS 26 开启「过滤未知发件人」后，被静默筛走的陌生短信是否仍触发自动化未经验证，
  快递短信多为陌生号码——若发现漏触发，优先检查该开关。
- 为什么不能像短信过滤 App 那样免配置？那类 App 用的 Message Filter Extension 被
  系统限定为纯分类器（内容传不出扩展、不能触发任何动作、iMessage 与联系人短信
  根本不经过它）——快捷指令自动化是 iOS 上唯一的「短信 → 动作」合规通道。
